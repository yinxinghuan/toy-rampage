# Toy Rampage / 玩具大暴走

AlterU 平台发布分支，基于独立商用游戏 r50 制作的快照。玩家在机械玩具工坊中摆放与融合武器，扩展棋盘，阻挡逐波来袭的玩具敌人。支持中文与英文、触控拖拽、六关各八波。本版本无充值，进度保存在当前浏览器；跨设备不会同步。

外部游戏主线独立开发。本仓库的源码和素材公开，仅代表此平台快照，不代表最终商业版本。游戏机制参考《保卫向日葵》的公开试玩体验；未使用其代码、美术或音频。

```sh
npm ci
npm test
npm run build
npm run dev
```
